# Learn *score*

*ossia score* {{ site.score_version }}
{: .label .label-green}

A graded course for *ossia score*, the interactive sequencer for the intermedia arts. Forty-seven units, each between ten and fifteen minutes, take a reader from a first installation to a complete interactive work.

The course is not a replacement for the [reference documentation]({{ site.docs_baseurl }}). The reference answers "what does this control do"; the course answers "what do I do next, and why". Every lesson links outward to the reference rather than restating it.

[Start the course]({{ site.baseurl }}/learn){: .btn .btn-primary }
[Download the example documents]({{ site.baseurl }}/downloads){: .btn }

## How the course is built

Each unit is one page, written so that it also serves as the script for a future video. A unit states what you need before starting, what you will build, the concepts involved, a numbered walkthrough, the mistakes learners most often make, and one exercise with a success criterion. Every unit ships a runnable score file.

Six *Make it work* milestones are interleaved between the concept clusters. A milestone introduces nothing new; it assembles what the preceding lessons taught into an artefact you can perform or install.

## What you need

A computer running Linux, macOS, or Windows, and *score* {{ site.score_version }}. **No additional hardware is required at any point in the course.** Sensors, lighting fixtures, controllers, and multichannel or dome playback systems appear only in optional sidebars; the milestones themselves are verified on a laptop with emulated sensors, a software Art-Net receiver, keyboard-mapped controls, and a binaural fold-down of the spatial audio material.
